# ZOKA Mainnet Bug Bounty Pre-Launch Checklist

## Program setup

- [ ] Scope published (in-scope components and exclusions).
- [ ] Reward ranges approved by project governance.
- [ ] Submission channel and SLA published.
- [ ] Legal and safe-harbor policy published.

## Launch gate

- [ ] Program is public before mainnet launch window.
- [ ] Security contact and escalation route are active 24/7 in launch week.
- [ ] Critical-severity triage process tested with tabletop drill.
