# Anuncio de Discord: nodo 4.0.5 y ZSilent 4.0.7 (borrador)

Lo pega el usuario cuando las releases estén publicadas. Cada versión tiene
menos de 2.000 caracteres.

## Castellano

**Zoka Quantic Testnet v2 · nodo y minero 4.0.5 · ZSilent 4.0.7**

**Si minás, actualizá.** Hasta hoy, un pago llegaba a un minero solo si una semilla lograba conectarse a él. Con el minero detrás de un router, un pago podía esperar muchos bloques: el 3/11, uno esperó 11. Desde la 4.0.5, el nodo del minero les pide a las semillas los pagos pendientes y los baja en segundos.

**ZSilent 4.0.7**
• El saldo total ya no esconde lo que reserva un envío mientras espera un bloque. La tarjeta Pending muestra cuánto es.
• El explorador vuelve a listar los últimos bloques, y buscar un pago por su id dice si está pendiente o en qué bloque entró.

Misma cadena, mismas billeteras. Tor sigue siendo opcional.

Descargas y SHA-256: https://zoka.network

## English

**Zoka Quantic Testnet v2 · node and miner 4.0.5 · ZSilent 4.0.7**

**Miners, please update.** Until now a payment reached a miner only when a seed managed to connect to it. With the miner behind a router, a payment could wait many blocks: on Nov 3 one waited 11. From 4.0.5, the miner's node asks the seeds for their pending payments and fetches them in seconds.

**ZSilent 4.0.7**
• The total balance no longer hides what a send reserves while it waits for a block. The Pending card shows how much.
• The explorer lists the latest blocks again, and searching a payment id tells whether it is pending or which block holds it.

Same chain, same wallets. Tor stays optional.

Downloads and SHA-256: https://zoka.network
