# Wallets

ZOKA has two primary self-custodial wallet surfaces:

- **ZKAPriv** for Android.
- **ZSilent Core** for desktop.

Both are designed around local key ownership. Users should never enter a seed
phrase, spend key, or scan key into public websites, chats, forms, or support
tickets.

## Choosing a Wallet

| Wallet | Best For |
|---|---|
| ZKAPriv | Mobile private send/receive, balance recovery, recent activity, Android use. |
| ZSilent Core | Desktop wallet, local node control, mining, logs, and advanced operations. |

## Common Concepts

- **Recovery phrase** restores the account.
- **Scan key** lets a wallet detect incoming funds.
- **Spend key** authorizes spending.
- **`zka1...` address** is the user-facing receive address.
