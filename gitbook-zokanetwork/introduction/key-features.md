# Key Features

- **Private-by-default payments** for user-facing transfers.
- **Hidden balances** in public explorer views.
- **Hidden sender, receiver, and amount** for private transaction records.
- **Zero-knowledge proof infrastructure** for private transfer validation.
- **Nullifier-based double-spend prevention**.
- **RandomX proof-of-work** for public network mining.
- **CPU-oriented mining path** with open participation.
- **ZKAPriv Android wallet** for mobile self-custody.
- **ZSilent Core desktop wallet** for wallet, node, and miner control.
- **ZokaScan public explorer** with privacy-safe search.

## Product Surfaces

ZKAPriv focuses on mobile wallet usage: create, restore, send, receive, scan
chain data, and recover local balance/history. ZSilent Core focuses on desktop
participation: wallet, local node control, mining, logs, and dashboard metrics.

The public explorer is intentionally limited. It helps inspect blocks and
transaction availability without exposing private account histories.
