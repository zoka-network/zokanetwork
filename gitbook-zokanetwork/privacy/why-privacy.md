# Why Privacy Matters

## Fungibility

If transaction histories are public and easy to label, coins can become
non-fungible in practice. Privacy helps each unit of ZKA remain economically
equivalent.

## Financial Freedom

Users should not need to expose balances, counterparties, or financial behavior
to participate in a public blockchain.

## Data Protection

Wallet information is sensitive personal data. ZOKA keeps that view local to
the wallet owner.

## Self-Custody and Privacy Together

Privacy is strongest when it is paired with self-custody. A wallet that keeps
keys local but asks a server to calculate private history can still leak user
behavior. ZOKA's wallet flows are designed so public RPC provides chain data
while local wallet software reconstructs the user's private view.

Users still need good operational hygiene: protect backups, avoid posting scan
keys, prefer trusted network paths, and keep devices updated.
