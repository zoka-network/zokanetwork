# Developers

ZOKA is developed across several repositories.

The public docs should stay aligned with code and releases. If a claim is not
implemented, label it as planned or omit it.

## Main Languages

- Rust for the core node, CLI, wallet logic, mining, state, and RPC.
- Kotlin and Compose for ZKAPriv and ZSilent Core.
- TypeScript, React, and Tailwind for website and explorer frontends.
