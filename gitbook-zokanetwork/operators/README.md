# Node Operators

Operators run ZOKA full nodes, maintain local chain state, and may mine blocks.

Public operators should keep wallet secrets off public machines where possible,
use OS-level secret handling, and never commit deployment credentials.

## Recommended Baseline

- Linux x86_64 VPS or desktop host.
- 2 or more CPU cores.
- 4 GB RAM minimum, 8 GB preferred for RandomX-heavy operation.
- SSD storage.
- NTP synchronized system clock.
- Dedicated unprivileged service user.
